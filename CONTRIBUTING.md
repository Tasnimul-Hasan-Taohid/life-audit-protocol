# Contributing to LIFE AUDIT PROTOCOL

Thank you for your interest in contributing. Please read this document in full before proceeding.

---

## Before You Submit

Ask yourself the following questions:

1. Have you audited your own life choices before attempting to improve software that audits life choices?
2. Are you contributing to fix a bug, or to avoid being judged by the current system?
3. Do you have the emotional stability to receive automated feedback on your code?

If you answered "no" to any of the above, your pull request will be closed without review.

---

## Code Standards

All contributions must adhere to the following:

- Functions must be deterministic. Life is not. This codebase is.
- No comments expressing sympathy. The system does not do sympathy.
- Variable names must be precise. Do not name a variable `maybe` or `probably`. The system deals in certainties.
- All new judgment logic must be peer-reviewed by at least one person who has never given unsolicited advice and ignored it.

---

## Submitting a Pull Request

1. Fork the repository.
2. Create a branch: `git checkout -b feature/your-terrible-idea`
3. Write your changes.
4. Run the test suite: `python -m pytest tests/` — all tests must pass. Especially `test_no_excuses.py`.
5. Open a pull request with a clear description of what you changed and why you believe it was a good idea.
6. Wait.

---

## What We Will Accept

- Improvements to the Regret Probability Matrix (evidence-based only; anecdotes will not be accepted)
- New judgment templates covering underrepresented life scenarios
- Performance optimizations (the system already judges faster than most people process shame, but there is room to improve)
- Bug fixes

---

## What We Will Not Accept

- Contributions that soften verdicts
- A `--forgive` flag
- Anything described in the PR as "just a small quality of life improvement"
- Features requested by people who were recently audited

---

## Code of Conduct

Be professional. The system will be watching.

--

*All contributors implicitly agree to be subject to audit upon submission.*
